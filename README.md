##   Cocket Nova Examples and Getting Started

This repository contains examples and a getting started guide for the Cocket Nova - CH552 development board, which is based on the CH552 microcontroller. The examples are written for Arduino IDE and SDCC (Small Device C Compiler) and are designed to help you get started with the board quickly.
